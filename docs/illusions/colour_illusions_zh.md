# 颜色错觉

*眼睛看到的，并不是纸面上画的*

颜色、亮度、大小和形状并不是从图像上逐点读取的：视觉系统把每个区域与周围环境作比较，然后推测那里究竟是什么。这些错觉让我们看到这种推测是如何进行的。它们并非都与色相有关，有些只需要黑白对比。

请在屏幕上或用质量好的彩色打印件，以舒适的距离观看。每种错觉的强弱因人而异。少数错觉使用运动或闪烁：如感不适请停止观看。

> 所有图形均为本文档绘制。文字是根据所链接的维基百科条目（以 CC BY-SA 许可协议提供）写成的简短摘要。

## 颜色

<a id="contrast"></a>

### 同时对比

![同时对比](images/contrast.svg)

**看到什么**：四个小方块是同一种灰色。在深色底上它显得比在浅色底上更亮；在蓝色上偏黄，在黄色上偏蓝。

**为什么会这样**：颜色是按差异来判断的。周围环境会在明度和色相上把其中的区域推向相反方向。

**试一试**：在一张纸上开两个孔，只露出其中两个小方块：差异就消失了。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Contrast_effect)

<a id="bezold"></a>

### 贝措尔德效应

![贝措尔德效应](images/bezold.svg)

**看到什么**：黑色条纹间的红色显得更深更暗，白色条纹间的红色则显得更浅、偏粉。其实是同一种红色。

**为什么会这样**：当小面积的颜色交替排列时，眼睛会部分地把它们混合（同化）：红色沾上了邻色。威廉·冯·贝措尔德在只更换一种颜色来重新设计地毯时注意到了这一点。

**试一试**：离页面远一些：距离越远，混合越强。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Bezold_effect)

<a id="constancy"></a>

### 颜色恒常性

![颜色恒常性](images/constancy.svg)

**看到什么**：同一幅马赛克的两个副本分别在暖光和冷光下（上方的圆点）。第二行第二块在左边显得偏蓝，在右边显得偏黄，其实是同一种中性灰。

**为什么会这样**：为了让物体保持可辨认，大脑会估计光源的颜色并将其扣除。在一片橙色场景中看到的灰色，会被理解为偏蓝的表面。

**试一试**：把两块灰色以外的部分全部遮住。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Color_constancy)

<a id="afterimage"></a>

### 负后像

![负后像](images/afterimage.svg)

**看到什么**：盯住彩色圆环中央的点之后，右边孤立的点周围仿佛出现了其他颜色的圆环：红、绿、黄。

**为什么会这样**：对某种颜色作出反应的细胞会疲劳（适应）。看白色表面时，其他细胞反应更强，于是看到互补色。

**试一试**：眼睛不动，盯住左边的点 30 秒，再看右边的点并眨眼。

[维基百科条目](https://zh.wikipedia.org/wiki/%E5%BE%8C%E5%83%8F)

<a id="lilac"></a>

### 丁香追逐者

![丁香追逐者](images/lilac.svg)

**看到什么**：盯住十字，会看到一个缺口沿着淡紫色圆点组成的圆环移动；接着缺口变成绿色圆点，过一会儿淡紫色圆点可能完全消失。

**为什么会这样**：移动的缺口是似动现象（φ现象）。圆点消失处出现相反颜色（绿色）的后像。周边视野中静止的模糊圆点会从意识中淡出（特克斯勒效应）。

**试一试**：注视十字至少 30 秒。这个动画由杰里米·欣顿在 2005 年之前制作。

[维基百科条目](https://zh.wikipedia.org/wiki/%E4%B8%81%E9%A6%99%E8%BF%BD%E9%80%90%E8%80%85)

<a id="mccollough"></a>

### 麦科洛效应

![麦科洛效应](images/mccollough.svg)

**看到什么**：轮流注视红色横条纹和绿色竖条纹后，下方的黑白图案看上去带有颜色：横条纹处偏绿，竖条纹处偏粉。

**为什么会这样**：视觉系统对与方向绑定的颜色产生了适应。塞莱斯特·麦科洛于 1965 年描述了它；效应可持续数小时甚至数月。

**试一试**：在两个彩色条纹之间每隔几秒交替注视，持续几分钟，然后看小图案。注意：该效应可能持续很久。

[维基百科条目](https://zh.wikipedia.org/wiki/%E9%BA%A5%E7%A7%91%E6%B4%9B%E6%95%88%E6%87%89)

<a id="chromostereopsis"></a>

### 色立体视觉

![色立体视觉](images/chromostereopsis.svg)

**看到什么**：黑底上的红色和蓝色似乎不在同一平面：多数人觉得红色浮在蓝色前面，也有人觉得它退到后面。

**为什么会这样**：晶状体对短波和长波的折射程度不同（色差），两种颜色在两眼中落在略有不同的位置，大脑把这种偏移理解为深度。

**试一试**：在光线较暗的房间里用双眼观看；戴眼镜和不戴眼镜都试试。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Chromostereopsis)

## 亮度与对比

<a id="checker"></a>

### 棋盘阴影错觉

![棋盘阴影错觉](images/checker.svg)

![棋盘阴影错觉](images/checker_2.svg)

**看到什么**：方格 A 看起来比方格 B 暗得多。其实两者的灰度完全相同，第二幅图中的连接条可以证明。

**为什么会这样**：大脑认出这是带阴影的棋盘并对阴影作了校正：B 应该是浅色格，于是就看成浅色。爱德华·阿德尔森于 1995 年发表了这一错觉。

**试一试**：用两张纸遮住棋盘其余部分，只露出 A 和 B。

[维基百科条目](https://zh.wikipedia.org/wiki/%E6%A3%8B%E7%9B%A4%E9%99%B0%E5%BD%B1%E9%8C%AF%E8%A6%BA)

<a id="white"></a>

### 怀特错觉与蒙克错觉

![怀特错觉与蒙克错觉](images/white.svg)

![怀特错觉与蒙克错觉](images/white_2.svg)

**看到什么**：嵌在黑条纹中的灰色短条看起来比嵌在白条纹中的更亮。彩色版本（蒙克）中，同一种红色在一侧显得橙，在另一侧显得紫。

**为什么会这样**：这与单纯对比的预测相反：眼睛似乎把每根短条与它所嵌入的条纹归为一组。

**试一试**：透过纸上剪出的小孔比较两组短条。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/White%27s_illusion)

<a id="mach"></a>

### 马赫带

![马赫带](images/mach.svg)

**看到什么**：每条均匀的灰带在靠近较亮邻带处显得更暗，靠近较暗邻带处显得更亮，好像带有凹槽。

**为什么会这样**：视网膜上相邻细胞相互抑制（侧抑制），从而夸大边缘。恩斯特·马赫于 1865 年描述了这一效应。

**试一试**：只留一条灰带，遮住其余：它是完全均匀的。

[维基百科条目](https://zh.wikipedia.org/wiki/%E9%A9%AC%E8%B5%AB%E5%B8%A6)

<a id="cornsweet"></a>

### 康士维错觉

![康士维错觉](images/cornsweet.svg)

**看到什么**：左半部分看起来比右半部分亮。远离中线处，两边是同一种灰。

**为什么会这样**：只有边缘不同：一侧渐亮，另一侧渐暗。视觉系统把边缘处的阶跃当作整个区域之间的差异。

**试一试**：在中线上放一支铅笔，两半就变得一样了。

[维基百科条目](https://zh.wikipedia.org/wiki/%E5%BA%B7%E5%A3%AB%E7%B6%AD%E9%8C%AF%E8%A6%BA)

<a id="grid"></a>

### 栅格错觉：赫尔曼与闪烁

![栅格错觉：赫尔曼与闪烁](images/grid.svg)

![栅格错觉：赫尔曼与闪烁](images/grid_2.svg)

**看到什么**：白色栅格的交叉处出现灰斑，唯独注视处没有。在灰色栅格上加圆点后，黑点似乎忽闪忽灭。

**为什么会这样**：赫尔曼栅格（1870 年）长期只用侧抑制来解释；后来的实验（把线条弯曲它就消失）表明，它还取决于大脑皮层如何处理直线。闪烁版本在 1990 年代被报道。

**试一试**：先让目光在栅格上游走，再盯住一个交叉点。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Grid_illusion)

<a id="ehrenstein"></a>

### 埃伦施泰因错觉

![埃伦施泰因错觉](images/ehrenstein.svg)

**看到什么**：在线条未相交就中断的地方，似乎出现了比纸还白的亮圆盘。

**为什么会这样**：线端暗示上面盖着一个遮住交叉点的形状。大脑画出它的轮廓（错觉轮廓）并填上亮度。

**试一试**：在脑中或用铅笔把缺口连上：圆盘就消失了。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Ehrenstein_illusion)

<a id="irradiation"></a>

### 辐照错觉

![辐照错觉](images/irradiation.svg)

**看到什么**：黑底上的白方块看起来比白底上的黑方块大，其实大小相同。

**为什么会这样**：光在眼内散射，亮区在视网膜上扩散开来。伽利略在 1632 年提到过它；亥姆霍兹给它命名。

**试一试**：量一量两个方块。

[维基百科条目](https://zh.wikipedia.org/wiki/%E8%BE%90%E7%85%A7%E9%94%99%E8%A7%89)

## 大小与长度

<a id="ebbinghaus"></a>

### 艾宾浩斯错觉（铁钦纳圆）

![艾宾浩斯错觉（铁钦纳圆）](images/ebbinghaus.svg)

**看到什么**：被大圆包围的橙色圆看起来比被小圆包围的小。

**为什么会这样**：大小是相对于背景判断的；周围圆的距离和间隔也有影响。

**试一试**：用手指遮住蓝色圆。

[维基百科条目](https://zh.wikipedia.org/wiki/%E8%89%BE%E8%B3%93%E6%B5%A9%E6%96%AF%E9%8C%AF%E8%A6%BA)

<a id="muller_lyer"></a>

### 米勒-莱尔错觉

![米勒-莱尔错觉](images/muller_lyer.svg)

**看到什么**：箭羽朝外的线段看起来比箭羽朝内的长。两者其实一样长，与下方红线相同。

**为什么会这样**：箭羽改变了线段端点看起来所在的位置；一种解释把它与立体观看的房间和建筑的墙角联系起来。弗朗茨·米勒-莱尔于 1889 年描述了它。

**试一试**：用虚线参照线比较两条线段。

[维基百科条目](https://zh.wikipedia.org/wiki/%E7%B1%B3%E5%8B%92-%E8%8E%B1%E5%B0%94%E9%94%99%E8%A7%89)

<a id="ponzo"></a>

### 庞佐错觉

![庞佐错觉](images/ponzo.svg)

**看到什么**：上面的黄色横条看起来比下面的长。

**为什么会这样**：会聚的线条像铁轨一样暗示距离：纸面上大小相同但更远的横条，实际应当更大。

**试一试**：量一量两根横条，或把页面倒过来看。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Ponzo_illusion)

## 弯曲与倾斜的线条

<a id="cafe"></a>

### 咖啡墙错觉

![咖啡墙错觉](images/cafe.svg)

**看到什么**：灰色的砖缝线看起来交替倾斜，其实它们相互平行且水平。

**为什么会这样**：错开的黑白瓷砖加上中间灰度的砖缝，在每条线上形成许多倾斜的小单元。理查德·格雷戈里于 1973 年以布里斯托尔一家咖啡馆的墙命名。

**试一试**：把页面几乎侧过来，沿着一条砖缝看。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Caf%C3%A9_wall_illusion)

<a id="fraser"></a>

### 弗雷泽螺旋

![弗雷泽螺旋](images/fraser.svg)

**看到什么**：似乎有一条螺旋线向中心盘绕。其实没有螺旋：黑白绳纹构成的是同心圆。

**为什么会这样**：每一小段都是倾斜的，扭转的背景又加强了倾斜，于是眼睛把它们连成螺旋。詹姆斯·弗雷泽于 1908 年描述了它。

**试一试**：把手指放在一圈绳纹上沿着走：你会回到起点。

[维基百科条目](https://zh.wikipedia.org/wiki/%E5%BC%97%E9%9B%B7%E6%BE%A4%E8%9E%BA%E6%97%8B%E9%8C%AF%E8%A6%BA)

<a id="hering"></a>

### 黑林错觉

![黑林错觉](images/hering.svg)

**看到什么**：两条红线中部似乎向外鼓出。其实它们是平行直线。

**为什么会这样**：与放射线之间的夹角被高估，图案还暗示着向纵深的运动。埃瓦尔德·黑林于 1861 年发现。

**试一试**：拿直尺贴着一条红线比一比。

[维基百科条目](https://zh.wikipedia.org/wiki/%E9%BB%91%E6%9E%97%E9%94%99%E8%A7%89)

<a id="wundt"></a>

### 冯特错觉

![冯特错觉](images/wundt.svg)

**看到什么**：两条红线中部似乎向内弯曲、彼此靠近。其实它们是平行直线。

**为什么会这样**：它与黑林图形相反：放射线从两侧的点发出，夹角使红线向另一个方向变形。威廉·冯特于 1898 年描述了它。

**试一试**：与黑林错觉对照着看。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Wundt_illusion)

<a id="orbison"></a>

### 奥比森错觉

![奥比森错觉](images/orbison.svg)

**看到什么**：红色正方形看起来变了形：边弯曲，角被拉扯。

**为什么会这样**：与黑林图形一样，边与背景圆环的交叉干扰了对各边方向的感知。威廉·奥比森于 1939 年描述了它。

**试一试**：用直尺检查各边。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Orbison_illusion)

<a id="zollner"></a>

### 策尔纳错觉

![策尔纳错觉](images/zollner.svg)

**看到什么**：长斜线似乎时而靠拢、时而分开。其实它们彼此平行。

**为什么会这样**：短线以一定角度与长线相交，视觉系统夸大锐角，使每条长线略微旋转。约翰·策尔纳于 1860 年报告了它。

**试一试**：从页面一角沿着长线看过去。

[维基百科条目](https://zh.wikipedia.org/wiki/%E7%AD%96%E5%B0%94%E7%BA%B3%E9%94%99%E8%A7%89)

<a id="poggendorff"></a>

### 波根多夫错觉

![波根多夫错觉](images/poggendorff.svg)

![波根多夫错觉](images/poggendorff_2.svg)

**看到什么**：从左侧进入灰色方块的黑线，似乎从右侧以蓝线的位置穿出。实际上它接的是上面那条黑线，第二幅图可以证明。

**为什么会这样**：线与方块之间的锐角被看得比实际大，使感知到的路径发生偏移。最早是在策尔纳本人的图中被注意到的。

**试一试**：用直尺延长左边的线。

[维基百科条目](https://zh.wikipedia.org/wiki/%E6%B3%A2%E6%A0%B9%E5%A4%9A%E5%A4%AB%E9%94%99%E8%A7%89)

<a id="tilt"></a>

### 倾斜错觉与倾斜后效

![倾斜错觉与倾斜后效](images/tilt.svg)

**看到什么**：两个内圆里的条纹都是竖直的，却似乎朝与周围条纹相反的方向倾斜。

**为什么会这样**：对相近方向敏感的细胞相互抑制，把感知到的角度推开。长时间看倾斜条纹，对随后看到的东西也有类似影响。

**试一试**：遮住外环，比较两个内圆。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Visual_tilt_effects)

## 静止图像中的运动

<a id="motion"></a>

### 运动错觉

![运动错觉](images/motion.svg)

**看到什么**：圆环似乎在缓慢旋转，尤其是没有直接注视的那些。

**为什么会这样**：对比度不同的色块被处理的延迟略有差异，每次细微的眼动又让这个序列重新开始；运动检测器便把它当成运动。

**试一试**：把目光从一个轮子移到另一个，或眨眨眼。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Illusory_motion)

<a id="drift"></a>

### 周边漂移错觉

![周边漂移错觉](images/drift.svg)

**看到什么**：用眼角余光看时，由灰度渐变组成的圆环似乎在转动。

**为什么会这样**：从暗到亮反复出现的渐变（锯齿波）刺激周边视野的运动检测器；看到的运动方向是从暗到亮。

**试一试**：看图形旁边并快速眨眼。

[维基百科条目 (英文)](https://en.wikipedia.org/wiki/Peripheral_drift_illusion)

## 图形、背景与不可能的物体

<a id="rubin"></a>

### 鲁宾花瓶

![鲁宾花瓶](images/rubin.svg)

**看到什么**：一个浅色花瓶，或两张相对的深色侧脸：非此即彼，很难同时看到。

**为什么会这样**：共用的轮廓同一时刻只能属于一方：被当作图形的一方获得形状，其余成为背景。埃德加·鲁宾在 1915 年前后研究过它。

**试一试**：试着随意切换，并数一数它自行翻转了几次。

[维基百科条目](https://zh.wikipedia.org/wiki/%E9%AD%AF%E8%B3%93%E4%B9%8B%E7%9B%83)

<a id="penrose"></a>

### 彭罗斯三角

![彭罗斯三角](images/penrose.svg)

**看到什么**：由三根方形梁构成的实心三角形，每根都与下一根成直角相接。

**为什么会这样**：每个角单独看都合理，三个角合起来却不能成立：这样的物体并不存在。奥斯卡·路透斯沃德于 1934 年画出它；莱昂内尔和罗杰·彭罗斯使它广为人知，它还启发了埃舍尔的《瀑布》。

**试一试**：每次遮住一个角：剩下的部分就变得可能了。

[维基百科条目](https://zh.wikipedia.org/wiki/%E6%BD%98%E6%B4%9B%E6%96%AF%E4%B8%89%E8%A7%92)
